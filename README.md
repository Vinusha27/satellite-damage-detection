# Satellite-Based Disaster Damage Detection

## Overview
This project detects environmental damage using satellite imagery by analyzing vegetation changes through NDVI (Normalized Difference Vegetation Index).

## Features
- NDVI calculation using Red and NIR bands
- Change detection (before vs after)
- Damage percentage estimation
- Visualization (NDVI maps + damage heatmap)
- Flask web application for real-time analysis

## Tech Stack
- Python
- NumPy
- Matplotlib
- Flask
